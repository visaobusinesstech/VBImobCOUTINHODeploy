# Pasta `project/` (Radar Vite + Supabase)

**Pode apagar** a pasta `project/` na raiz do zip. O CRM que o cliente usa é só:

`VBSOLUTIONCRMCodigoFonte-main/` (backend + frontend + DOCUMENTACAO)

O VBSolution **não importa** código de `project/src`. Imóveis, pipeline, RadarZAP, prompts, tickets, campanhas etc. estão no React + Express.

O que você perde ao apagar:

- o app Vite original (Lovable/Supabase)
- telas com visual 100% idêntico ao Radar antigo (no VB as telas imobiliárias extras usam o tema do CRM e Postgres)

Não apague `VBSOLUTIONCRMCodigoFonte-main/`.
